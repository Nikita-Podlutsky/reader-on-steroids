Смотри у тебя есть образец frontend части написанный на vanilla js в файле text.html. Тебе необходимо создать хорошо читаемую для человека систему файлов, реализующих frontend приложение по образцу, но тебе необходимо использовать не vanilla js, а вот такой стек технологий:

React 18 + TypeScript
D3.js v7
Tailwind CSS
React Query
Three.js (для 3D)
Vite.
При заходе на сайт пользователь видит пустую страницу с строкой поиска. После ввода запроса, строка поиска сдвигается в верх экрана, а в центральной прямоугольной области будут располагаться "кружочки" основных статей в разных тематиках (тематика соответствует цвету "кружочка") по этой теме, которые вернет сервер, как прописано в spec.yaml. В левой боковой области будут находится фильтры по годам. При нажатии на "кружочек" статьи, интересующей пользователя, в боковом меню появляется описание статьи, присланное сервером. А в центральной области появляется граф с "кружочками", связанными с данной статьей ("кружочки" это узлы графа, который прислал сервер и который состоит из статей) в тематике данной статьи (то есть одинакового цвета). Еще раз напоиминаю, что тебе необходимо создать читабельную систему файлов с использованием данного стека технологий. А также тебе необходимо создать файл с расширением .md для ведения документации этого проекта и инструкций по сборке и запуску.
