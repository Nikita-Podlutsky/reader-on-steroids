# ScholarMap - Карта научных идей

**ScholarMap** - это интерактивное веб-приложение для визуализации и исследования графа научных статей. Проект позволяет пользователям искать статьи по темам, визуализировать связи между ними и изучать детали публикаций.

## 🚀 Технологический стек

- **React 18** - библиотека для построения пользовательского интерфейса
- **TypeScript** - типизированный JavaScript для повышения надежности кода
- **Vite** - быстрый сборщик и dev-сервер
- **Tailwind CSS** - utility-first CSS фреймворк для стилизации
- **D3.js v7** - библиотека для создания интерактивных графов
- **React Query (@tanstack/react-query)** - управление серверным состоянием и кэшированием
- **Axios** - HTTP-клиент для запросов к API
- **Three.js** - библиотека для 3D-визуализации (опционально для будущих улучшений)

## 📋 Требования

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 или **yarn** >= 1.22.0

## ⚙️ Предварительная установка Node.js

Если у вас не установлен Node.js, выполните следующие шаги:

### Для Windows:

1. **Скачайте Node.js** с официального сайта: https://nodejs.org/
   - Рекомендуется версия LTS (Long Term Support)
   - Скачайте установщик `.msi` для Windows

2. **Запустите установщик**
   - Следуйте инструкциям мастера установки
   - Убедитесь, что отмечена опция "Add to PATH"
   - Примите все настройки по умолчанию

3. **Проверьте установку**
   Откройте новое окно PowerShell и выполните:
   ```powershell
   node --version
   npm --version
   ```
   Вы должны увидеть номера версий (например, v20.10.0 и 10.2.3)

### Альтернативный способ через Chocolatey:

```powershell
# Установите Chocolatey (если еще не установлен)
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# Установите Node.js через Chocolatey
choco install nodejs-lts -y

# Перезапустите PowerShell и проверьте
node --version
npm --version
```

Создайте файл `.env` в корне проекта на основе `.env.example`:

```env

```

## 🔧 Решение проблем

### Ошибка "npm не распознано"
- Убедитесь, что Node.js установлен: откройте **новое** окно PowerShell и выполните `node --version`
- Перезагрузите компьютер после установки Node.js
- Проверьте, что путь к Node.js добавлен в PATH (обычно `C:\Program Files\nodejs\`)

### Ошибки при установке зависимостей
```powershell
# Очистите кэш npm
npm cache clean --force

# Удалите node_modules и package-lock.json
Remove-Item -Recurse -Force node_modules
Remove-Item package-lock.json

# Установите заново
npm install
```

### Порт 3000 уже занят
Измените порт в `vite.config.ts` или завершите процесс, использующий порт 3000

## 🎯 Основные возможности

### 1. Поиск статей
- При первом заходе пользователь видит страницу поиска по центру
- После ввода запроса строка поиска перемещается в шапку
- Возвращается граф статей по заданной теме

### 2. Визуализация графа
- Интерактивная визуализация с помощью D3.js
- Узлы графа представляют статьи, окрашенные по доменам (cs, math, physics и т.д.)
- Размер узла зависит от количества цитирований
- Перетаскивание узлов для изменения расположения
- Hover-эффекты с подробной информацией

### 3. Фильтрация
- Фильтры по годам публикации
- Фильтры по научным доменам
- Фильтр по минимальному количеству цитирований

### 4. Детали статей
- Клик по узлу открывает боковую панель с информацией о статье
- Отображение похожих статей
- Просмотр авторов, года, цитирований и тегов

## 🔧 API интеграция

Приложение работает с REST API согласно спецификации в `spec.yaml`:

### Эндпоинты

- **GET /search** - поиск статей по теме
- **POST /filter** - фильтрация графа статей
- **GET /articles/{id}** - получение детальной информации о статье

Полная спецификация API доступна в файле `spec.yaml`.

## 🧪 Разработка

### Добавление новых компонентов

Компоненты размещаются в соответствующих директориях:
- `src/components/ui/` - переиспользуемые UI компоненты
- `src/components/layout/` - компоненты макета
- `src/components/graph/` - компоненты для визуализации

### Работа с типами

Все типы данных определены в `src/types/index.ts` и соответствуют API спецификации.

### Работа с API

Используйте кастомные хуки из `src/hooks/useApi.ts`:
- `useSearch(query)` - поиск статей
- `useArticle(id)` - получение информации о статье
- `useFilter()` - фильтрация графа
